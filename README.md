## Featured project: [Trend2Video Pro](https://github.com/2417467487-hub/Trend2Video-Pro)

A local workflow that turns a trend or URL into a short-video package: script, storyboard, MP4, subtitles, metadata, and a quality report. Built with FastAPI, Streamlit, SQLite, and MoviePy.
